### Current adjudication thesis

The defensible question is not whether the reported SPP/ORQA result is wrong or downward-biased. It is whether sufficient same-instance convergence evidence or an error certificate exists to treat the reported `0.183429` result as a quantitatively controlled N=51 classical comparator.

The strongest presently established facts are:

**(a)** the QAT entry supplies no uncertainty bounds for SPP;

**(b)** ZZd3 is tabulated at W=16, ε₀=5×10⁻⁸, numerically the loosest reported truncation threshold among the listed observables;

**(c)** at cycle 16 this run consumed 7,961 s, versus 31,559 s for the same-W ZZd2 run at ε₀=10⁻⁹ — approximately 25.2% as much runtime;

**(d)** the submitters themselves state that convincing classical convergence is not achieved;

**(e)** no small-N locality argument can certify the late-cycle N=51 observable because the formal causal cone spans all 51 qubits by cycle 10; and

**(f)** the source table contains a separately verifiable late-cycle SPP anomaly in the ZZd2/ZIZ data that warrants confirmation of the underlying numerical values.

Public claims should remain framed as requests for convergence evidence and source-value confirmation, not assertions that the SPP computation is incorrect.
