# tnbench

Independent classical benchmarking of quantum advantage candidates.

Scope: reproduce and stress-test the *classical* side of open submissions
to the Quantum Advantage Tracker. Primary target is sparse Pauli
propagation (SPP) truncation error; PEPS-BP as cross-check.

Discipline: every run freezes a config, hashes it, and logs the hash
alongside the result. Predictions are written to notes/ before execution.

Status: setup. No results yet.
